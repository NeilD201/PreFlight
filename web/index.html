    Vector settings

    Connect Meta Muse Spark for circuit review and repair planning.

    Model: muse-spark-1.3-contributor · Contributor billing $0.10 in / $0.002 cached / $0.20 out per 1M tokens

    Uses Meta’s Model API. Contributor requests may be used by Meta to improve its models. Project chat is supported; web search grounds answers with cited sources.

    Complete investigation: up to 12 requests per review, 20 per repair action, 4 per chat answer and 8 per firmware plan. Analysis output up to 80k tokens per evidence request (160k for design reviews), well under the model's shared context budget; repair proposals stay small and strictly validated. Limits reset for each action; the euro spending cap in usage tracking still applies.

    Save settings is free. Save & test sends one small paid request. Opening the app does not test the key.

    Keys stay in macOS Keychain, outside reports and browser storage.

    Vector sends the circuit evidence needed for the request to Meta only; there is no automatic provider fallback. Save & test checks the Meta key with one small request.

    External connections

    Meta: Vector reviews, questions and repair planning send selected design evidence and your context to Meta Muse Spark.

    LCSC: part searches send part numbers, values and packages; the app downloads product information and datasheets.

    Reference documents: supported checks may download public PDFs or layouts from Microchip, Analog Devices, Nordic and Johanson.

    KiCad checks, project files and saved reports stay on this computer. Manufacturer comparisons use built-in profiles; the app does not place orders. No analytics or tracking service is connected.
